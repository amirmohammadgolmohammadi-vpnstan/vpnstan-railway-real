# VPNSTAN v27 — Full Backup / Restore

## بکاپ کامل
از Settings → «بکاپ کامل پنل» یک فایل `VPNSTAN-v27-backup.vpnstan` دریافت می‌شود.

این فایل شامل دیتابیس کامل پنل است؛ بنابراین کانفیگ‌ها، Subscriptionها، مصرف و ترافیک ذخیره‌شده، تنظیمات، کاربران و پنل‌های فرزند، اطلاعات ربات Telegram، کیف پول و سفارش‌ها منتقل می‌شوند.

## بازیابی
در پنل جدید v27 وارد Settings شوید، فایل بکاپ را انتخاب و «بازیابی بکاپ» را بزنید. پس از بازیابی، پنل با اطلاعات پنل قبلی بالا می‌آید و Xray از روی دیتابیس/تنظیمات بازیابی‌شده دوباره ساخته می‌شود.

**هشدار:** فایل بکاپ شامل اطلاعات حساس مثل هش رمزهای ورود و توکن ربات Telegram است؛ آن را عمومی نکنید.
