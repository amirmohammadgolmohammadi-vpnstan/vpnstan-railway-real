# VPNSTAN Telegram Bot – Professional Store Mode

این نسخه امکانات حرفه‌ای فروشگاهی الهام‌گرفته از الگوی ربات‌های فروش VPN را اضافه می‌کند؛ کپی سورس یا برند شخص ثالث نیست.

## امکانات مشتری
- منوی فروش با دکمه‌های اینلاین
- حساب کاربری
- نمایش اشتراک‌های خریداری‌شده
- کیف پول
- تست رایگان قابل تنظیم
- تمدید و خرید حجم اضافه از مسیر خرید پلن
- سیستم دعوت دوستان و کد Referral
- پشتیبانی و ثبت تیکت
- سفارش‌ها و وضعیت سفارش
- تحویل خودکار Subscription بعد از تأیید ادمین

## امکانات ادمین
- `/stats` آمار کاربران و سفارش‌ها
- `/walletadd USER_ID AMOUNT` افزایش موجودی کیف پول
- `/broadcast TEXT` ارسال همگانی
- تنظیم متن خوش‌آمدگویی و پشتیبانی
- تنظیم تست رایگان (حجم/روز)
- تنظیم پاداش دعوت
- تنظیم کانال عضویت اجباری (فیلد تنظیمات اضافه شده؛ منطق احراز عضویت در این نسخه فعال نشده است)

## پرداخت
پرداخت همچنان دستی است و تأیید توسط ادمین انجام می‌شود. درگاه پرداخت خودکار بدون اتصال به API درگاه مشخصی فعال نشده است.
