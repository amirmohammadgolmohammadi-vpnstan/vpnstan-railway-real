# VPNSTAN v28 — Subscription UI

این نسخه ظاهر صفحه عمومی ساب/کانفیگ را مطابق طرح ارسالی بازطراحی می‌کند.

- هیچ endpoint یا قابلیت قبلی حذف نشده است.
- لینک Subscription، QR، کپی کانفیگ، دانلود Subscription و وضعیت مصرف حفظ شده‌اند.
- کانال رسمی `@vpnstan1` در هدر، فوتر و کارت سازنده حفظ شده است.
- در لیست Subscription پنل، دکمه «نمایش ساب» برای بازکردن همین صفحه اضافه شده است.
- داده‌های مصرف از endpoint قبلی `/sub-status/<id>` به‌صورت زنده خوانده می‌شوند.
