# VPNSTAN v26 — Telegram Pro Management

This build keeps user service details and the expanded administration dashboard inside Telegram using inline keyboards.

## User side
- My subscriptions is a selectable service list.
- Each service opens detailed status, total/used/remaining traffic, percentage, expiry, remaining days, protocol, transport, creation date and subscription URL.
- Service actions include extension and extra-volume choices.

## Admin side
- Dashboard/statistics
- Users and user profiles
- Wallet credit
- System services and enable/disable
- Orders
- Wallet payment requests
- Card details
- Plans
- Tickets
- Store settings
- Broadcast

The UI uses Telegram inline keyboards rather than requiring complex slash commands. Telegram documents inline callback buttons and bot command menus in its official Bot API documentation.
