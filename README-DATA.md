# VPNSTAN v26 — Automatic /data

این نسخه هنگام شروع کانتینر، پوشه `/data` را خودش می‌سازد و دیتابیس را در `/data/vpnstan.db` قرار می‌دهد.

بنابراین نیازی نیست داخل کانتینر یا پروژه پوشه `/data` را دستی بسازید.

نکته: اگر Railway Volume روی `/data` وصل نشده باشد، این پوشه فقط در فایل‌سیستم همان کانتینر ایجاد می‌شود و با حذف/تعویض کانتینر ممکن است اطلاعات دائمی نماند. برای ماندگاری دائمی، Railway Volume را روی `/data` متصل کنید.
