# VPNSTAN Telegram Sales Bot

این نسخه بخش «ربات فروش تلگرام» دارد.

## راه‌اندازی
1. در پنل وارد «ربات تلگرام» شوید.
2. توکن BotFather را وارد کنید.
3. آیدی عددی ادمین تلگرام را وارد کنید.
4. پلن‌ها را به شکل زیر تنظیم کنید:

```text
50GB / 30 روز | 50 | 30 |
100GB / 60 روز | 100 | 60 |
```

ستون‌ها: `نام پلن | حجم GB | روز | قیمت`.

5. متن روش پرداخت را وارد و «ذخیره و فعال‌سازی» را بزنید.
6. ربات با Long Polling کار می‌کند و نیازی به Webhook یا دامنه جداگانه ندارد.

## روند فروش
- مشتری `/start` یا `/plans` را می‌زند.
- یک پلن را انتخاب می‌کند.
- پرداخت را طبق متن تنظیم‌شده انجام می‌دهد و «پرداخت کردم» را می‌زند.
- سفارش به آیدی ادمین ارسال می‌شود.
- ادمین داخل تلگرام «تأیید و ساخت کانفیگ» را می‌زند.
- پنل به‌صورت خودکار VLESS + WebSocket می‌سازد و Subscription را برای مشتری می‌فرستد.

این نسخه درگاه پرداخت بانکی/رمزارزی ندارد؛ تأیید پرداخت دستی است. برای درگاه خودکار باید API درگاه موردنظر مشخص شود.

## امنیت
توکن ربات را فقط در پنل وارد کنید و آن را عمومی یا داخل GitHub قرار ندهید. توکن در SQLite پنل ذخیره می‌شود و فقط ادمین پنل می‌تواند تنظیمات ربات را ببیند/تغییر دهد.
